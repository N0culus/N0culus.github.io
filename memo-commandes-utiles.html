Commandes utiles

Serveur HTTP Python

python3 -m http.server 8080

Voir et libérer un port

Voir les ports ouvert et filtrer avec grep :

sudo netstat -tulpn | grep 3080

Arrêter le port ouvert :

sudo kill <port>

Écoute avec netcat

nc -lvp 4444

Arguments utilisés: -l pour listen, on va venir écouter -p pour spécifier le port d’écoute (4444) -v pour spécifier le niveau de verbosité.

Exegol / NetExec

nxc :

nxc smb "$TARGET" -u '' -p '' --generate-hosts-file hosts
