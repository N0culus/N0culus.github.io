VLANs sur OPNsense

1. Aller dans :

Interfaces → Other Types → VLAN

Cliquer Add (+) : - Parent interface : ton interface physique (ex : igb0) - VLAN tag : ex 10 - Description : ex VLAN10-LAN

Répète pour chaque VLAN.

C. Assignation des interfaces

Aller dans :

Interfaces → Assignments

Tu vas voir tes VLANs apparaître sous forme de ports disponibles.
Pour chaque VLAN, clique sur + pour créer une vraie interface.

→ Exemple : - VLAN10 apparaît comme vlan0 - Tu cliques +, et tu obtiens une interface OPT1

Renomme-la en LAN_V10 par exemple.

D. Activer et configurer l’interface

Ouvre l’interface nouvellement créée :

  • Enable interface
  • IPv4 configuration : Static IP
  • Exemple IP : 192.168.10.1/24

Enregistre.

E. Ajouter un serveur DHCP (optionnel mais courant)

Services → ISC DHCPv4 → VLAN10
Active, puis configure :

  • Range : 192.168.10.10 – 192.168.10.150

F. Règles Firewall (là où beaucoup bloquent)

Aller dans :

Firewall → Rules → VLAN10 Par défaut : aucune règle = tout est bloqué. → Ajouter une règle autoriser tout au début pour tester :

Action : Pass   
Interface : VLAN10   
Source : VLAN10 net   
Destination : any

Ensuite, tu raffineras (VLAN vers internet seulement, accès à un serveur, etc.).

5. Perspectives alternatives / erreurs classiques

Alternative : utiliser un VLAN parent LAN + VLANs enfants

→ LAN = VLAN 1 untagged
→ VLAN 10, 20, 30 taggés
→ Switch en trunk vers OPNSense

Dans un environnement virtuel (Proxmox, ESXi, GNS3)

→ Le vSwitch / bridge DOIT être VLAN-aware
Sinon rien ne passe.

Si tu veux isoler des VLANs IoT

→ Bloquer tout sauf Internet
→ Autoriser DNS/DHCP vers OPNsense seulement.

ImportantMettre le port entre le switch et le routeur en dot1q (trunk, tagué) Et le port vers l'équipement en access avec le numéro du vlan
