Installer Arch Linux

Préparation de la clé USB bootable

Télécharger l'ISO officielle et la flasher avec Rufus sur Windows

AstuceUtiliser Rufus avec le mode "Écrire en mode image ISO", schéma GPT, cible UEFI (non CSM). Ventoy peut poser des problèmes de compatibilité avec les dernières ISOs Arch.
AttentionSi le disque interne n'apparaît pas au démarrage : entrer dans le BIOS (F2), aller dans System Configuration → SATA Operation et passer de RAID à AHCI.

Clavier & Connexion Internet

Une fois sur le prompt root@archiso, configurer le clavier et le réseau

# Passer le clavier en AZERTY français
loadkeys fr

# Connexion Wi-Fi via iwctl
iwctl
  # Dans le prompt [iwd]# :
  station wlan0 scan
  station wlan0 get-networks
  station wlan0 connect NOM_DU_RESEAU
  exit

# Vérifier la connexion
ping -c 3 archlinux.org

Vérification du disque

Vérifier que le disque interne est bien détecté

# Lister les disques disponibles
lsblk

# Résultat attendu :
# nvme0n1   476.9G  → disque interne NVMe
# sda         5G    → clé USB bootable
Danger🔴 Si nvme0n1 n'apparaît pas : redémarrer, entrer dans le BIOS (F2) et passer SATA Operation de RAID à AHCI.

Partitionnement avec gdisk

Créer 3 partitions sur le disque NVMe avec le schéma GPT

PartitionTailleTypeCodeUsage
nvme0n1p1512 MiBEFI Systemef00Boot UEFI
nvme0n1p28 GiBLinux swap8200Mémoire virtuelle
nvme0n1p3~230 GiBLinux filesystem8300Système racine /
# Lancer gdisk sur le disque NVMe
gdisk /dev/nvme0n1

# Supprimer les partitions existantes
d → 1    # supprimer partition 1
d        # supprimer partition 2 (auto)

# Créer partition EFI (512M)
n → Entrée → Entrée → +512M → ef00

# Créer partition swap (8G)
n → Entrée → Entrée → +8G → 8200

# Créer partition racine (reste du disque)
n → Entrée → Entrée → Entrée → Entrée

# Vérifier et écrire
p    # afficher le tableau de partitions
w    # écrire sur le disque
y    # confirmer

Formatage & Montage

Formater chaque partition avec le bon système de fichiers

# Formater la partition EFI en FAT32
mkfs.fat -F32 /dev/nvme0n1p1

# Initialiser le swap
mkswap /dev/nvme0n1p2

# Formater la partition racine en ext4
mkfs.ext4 /dev/nvme0n1p3

# Monter les partitions
mount /dev/nvme0n1p3 /mnt
mkdir -p /mnt/boot/efi
mount /dev/nvme0n1p1 /mnt/boot/efi
swapon /dev/nvme0n1p2

Installation du système de base

Installer les paquets essentiels et générer le fstab

# Installer le système de base + outils essentiels
pacstrap /mnt base linux linux-firmware networkmanager grub efibootmgr sudo vim

# Générer le fichier de montage automatique
genfstab -U /mnt >> /mnt/etc/fstab

# Entrer dans le système installé
arch-chroot /mnt

Configuration du système

Langue, fuseau horaire, hostname, mot de passe root

# Fuseau horaire Paris
ln -sf /usr/share/zoneinfo/Europe/Paris /etc/localtime
hwclock --systohc

# Langue française
echo "fr_FR.UTF-8 UTF-8" >> /etc/locale.gen
locale-gen
echo "LANG=fr_FR.UTF-8" > /etc/locale.conf
echo "KEYMAP=fr" > /etc/vconsole.conf

# Nom de la machine
echo "archleo" > /etc/hostname

# Mot de passe root
passwd

# Créer un utilisateur avec droits sudo
useradd -m -G wheel -s /bin/bash leo
passwd leo

# Activer sudo pour le groupe wheel
EDITOR=vim visudo
# → décommenter : %wheel ALL=(ALL:ALL) ALL

# Activer NetworkManager au démarrage
systemctl enable NetworkManager

Bootloader GRUB + Sécurisation

Installer GRUB et protéger les options avancées par mot de passe

# Installer GRUB pour UEFI
grub-install --target=x86_64-efi --efi-directory=/boot/efi --bootloader-id=ARCH
grub-mkconfig -o /boot/grub/grub.cfg

# Quitter le chroot et redémarrer
exit
reboot
# Générer un hash de mot de passe GRUB
grub-mkpasswd-pbkdf2

# Ajouter dans /etc/grub.d/40_custom :
# set superusers="root"
# password_pbkdf2 root grub.pbkdf2.sha512.10000.VOTRE_HASH
# menuentry "Arch Linux" --unrestricted { ... }

# Récupérer l'UUID de la partition racine
sudo blkid /dev/nvme0n1p3

# Regénérer la config GRUB
sudo grub-mkconfig -o /boot/grub/grub.cfg

Environnement de bureau KDE Plasma

Installer KDE Plasma avec SDDM comme gestionnaire de connexion

# Installer KDE Plasma complet
sudo pacman -S plasma kde-applications sddm

# Activer le gestionnaire de connexion graphique
sudo systemctl enable sddm

# Redémarrer sur le bureau
reboot

# Configurer le clavier en français sous KDE
localectl set-x11-keymap fr

Post-installation & Outils

Sécurité, outils sysadmin, shell amélioré, Docker, Exegol

# Pare-feu UFW
sudo pacman -S ufw
sudo systemctl enable --now ufw
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw enable

# Protection brute-force
sudo pacman -S fail2ban
sudo systemctl enable --now fail2ban
# Docker
sudo pacman -S docker
sudo systemctl enable --now docker
sudo usermod -aG docker leo

# Exegol (wrapper Python)
sudo pacman -S python-pip git
pip install exegol --break-system-packages
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
exegol install
# Installer Zsh et le définir comme shell par défaut
sudo pacman -S zsh
chsh -s /usr/bin/zsh

# Installer Oh My Zsh
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

# Plugins autocomplétion + coloration syntaxique
git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions
git clone https://github.com/zsh-users/zsh-syntax-highlighting ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting

# Dans ~/.zshrc, modifier :
# plugins=(git zsh-autosuggestions zsh-syntax-highlighting)

# Thème Powerlevel10k
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/themes/powerlevel10k
# Dans ~/.zshrc : ZSH_THEME="powerlevel10k/powerlevel10k"
source ~/.zshrc
# Suivre le wizard de configuration p10k
# Réseau & Scan
sudo pacman -S nmap wireshark-qt netdiscover arp-scan

# Monitoring
sudo pacman -S htop btop nethogs iftop

# Automatisation & Terminal
sudo pacman -S ansible tmux

# Utilitaires réseau
sudo pacman -S curl wget rsync traceroute whois bind

# AUR helper (yay)
sudo pacman -S --needed git base-devel
git clone https://aur.archlinux.org/yay.git
cd yay && makepkg -si

# Bureau à distance
sudo pacman -S remmina freerdp

# FortiClient VPN
yay -S forticlient-vpn
