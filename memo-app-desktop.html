Créer un lanceur .desktop

1. Rendre ton script exécutable

chmod +x /chemin/vers/mon_script.sh

2. Créer le fichier .desktop

Créer le fichier :

nano ~/.local/share/applications/MonScript.desktop

Coller :

[Desktop Entry]
Type=Application
Name=Mon Script
Exec=/chemin/vers/mon_script.sh
Icon=network-wired
Terminal=true
Categories=Utility;

Sauvegarder (Ctrl+O), Quitter (Ctrl+X).

4. Rendre le .desktop exécutable

chmod +x ~/.local/share/applications/MonScript.desktop

5. Résultat

  • L’application apparaît dans le menu (GNOME, KDE, XFCE…)
  • Tu peux l'épingler au dock
  • Tu peux remplacer l’icône (ex: network-wireless)
  • Tu peux renommer Name=...
