Sauvegarde externe & restauration

Disque externeRétentionRestauration

La sauvegarde complète part du PC local vers un disque dur externe. Elle couvre l'intégralité du VPS : mails, fichiers Nextcloud, certificats SSL, bases de données et toutes les configurations.

Vue d'ensemble

  • Rétention — 4 sauvegardes conservées (1 par semaine) ; la plus ancienne est supprimée automatiquement à chaque nouvelle sauvegarde.
  • Destination — /media/leo/DISQUE/backups-privatiq/YYYY-MM-DD/
  • Taille — ~1,9 Go par sauvegarde.

Structure d'une sauvegarde

2026-05-14/
├── configs/                      # Tous les fichiers de configuration
│   ├── mailcow.conf
│   ├── nextcloud-docker-compose.yml
│   ├── collabora-docker-compose.yml
│   ├── turnserver.conf           # Config Coturn
│   ├── sshd_config
│   ├── passwd-verify.lua         # Auth Dovecot
│   ├── postfix-sql/
│   └── dovecot-sql/
├── mailcow-data/                 # nginx, rspamd, sogo...
├── mailcow-ssl/                  # Certificats SSL et clés privées
├── mailcow-db.sql                # Base de données Mailcow
├── nextcloud-config/             # config.php
├── nextcloud-data/               # Apps, thèmes, templates
├── nextcloud-data-users/         # Fichiers utilisateurs
├── nextcloud-db.sql              # Base de données Nextcloud
└── site-vitrine/                 # Fichiers du site

Effectuer une sauvegarde

Prérequis : disque externe monté, connexion internet active, clé SSH configurée pour le VPS. Le script lance les rsync et les mysqldump, puis purge la sauvegarde la plus ancienne. L'opération dure 5 à 10 minutes selon la quantité de nouveaux fichiers. On vérifie ensuite la taille et le contenu du dossier daté.

Restauration complète (perte totale du VPS)

Contexte : nouveau VPS OVH Ubuntu 24.04, IP éventuellement différente, même domaine. Les étapes :

  1. Préparer le nouveau VPS (paquets, Docker).
  2. Restaurer la config SSH et le pare-feu UFW.
  3. Restaurer Mailcow (données + base).
  4. Restaurer Nextcloud (config, données, base).
  5. Restaurer Collabora.
  6. Restaurer Coturn.
  7. Restaurer le site vitrine.
  8. Vérifications finales.

Restauration partielle

On peut ne restaurer qu'une partie :

  • Uniquement les mails → réimport de la base Mailcow.
  • Uniquement les fichiers d'un utilisateur Nextcloud → copie du dossier utilisateur, suivie d'un files:scan.
  • Uniquement la base Nextcloud → réimport du dump SQL.
Points importantsSi l'IP du nouveau VPS change, mettre à jour les DNS OVH avant de démarrer les services. Les certificats sont sauvegardés, mais Let's Encrypt peut les régénérer via acme — ne pas forcer si les certs restants sont encore valides (90 jours). Après restauration Nextcloud, un files:scan --all est obligatoire pour réindexer les fichiers restaurés.
