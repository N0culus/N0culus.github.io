Aide-mémoire · Virtualisation

Haute disponibilité Ceph

Prérequis :

Avoir une deuxième carte réseau et la configurer en linux bridge avec une adresse par exemple : - proxmox : 10.0.0.1/24 - proxmox2 : 10.0.0.2/24 - proxmox3 : 10.0.0.3/24

Ajouts dans les hosts :

nano /etc/hosts

[!warning] A faire avec d'installer CEPH -> Création du cluster

Création du cluster : !i!i!i!i! A faire avant le ceph

Création sur le noeud 1 et join informations pour joindre les autres.

Installation du service :

Sur chaque noeuds :

Aller dans Ceph -> Installer Ceph -> Modifier Entreprise à No Subscription -> Installer

Cliquer sur Next -> Sélectionner la deuxième carte réseau (linux Bridge crée précédemment).

Ajout des moniteurs :

Dans l'onglet Ceph -> Monitor -> Dans la fenêtre du haut "Monitor", ajouter les deux autre noeuds en cliquant du Create

Pareil pour l'onglet Manager -> Create et ajoutez les autre noeuds.

Création d'un OSD :

On va donc aller dans OSD -> Créer OSD -> séléctionner le disque -> Créer
