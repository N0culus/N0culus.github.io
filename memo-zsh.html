Configurer ZSH + Oh My Zsh

Voici un setup complet et prêt à coller. Je vais te donner les commandes d'installation puis le bloc .zshrc final.

1. Installe Oh My Zsh (si pas encore fait)

sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"

2. Installe les plugins externes

# Autocomplétion basée sur l'historique (indispensable)
git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions

# Coloration syntaxique en temps réel
git clone https://github.com/zsh-users/zsh-syntax-highlighting ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting

# Completions supplémentaires pour des centaines de commandes
git clone https://github.com/zsh-users/zsh-completions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-completions

# Recherche floue dans l'historique + fichiers (Ctrl+R boosté)
sudo apt install fzf -y

# Navigation intelligente entre dossiers (remplace cd)
curl -sS https://raw.githubusercontent.com/ajeetdsouza/zoxide/main/install.sh | bash

3. Bloc à coller dans ton ~/.zshrc

Ouvre le fichier avec nano ~/.zshrc, remplace la ligne plugins=(git) existante et ajoute le bloc de config à la fin :

# Plugin Manager ───────────────────────────────────────────────────────────
export ZSH="$HOME/.oh-my-zsh"
ZSH_THEME="robbyrussell"  # Change ici pour un autre thème

# Plugins ──────────────────────────────────────────────────────────────────
plugins=(
  git                        # Aliases git (gst, gco, gp…)
  zsh-autosuggestions        # Autocomplétion depuis l'historique → touche →
  zsh-syntax-highlighting    # Coloration des commandes en temps réel
  zsh-completions            # Completions pour curl, docker, npm, pip…
  sudo                       # Double Echap pour ajouter sudo devant la commande
  z                          # Saut rapide vers dossiers fréquents (z monprojet)
  fzf                        # Ctrl+R = recherche floue dans l'historique
  docker                     # Autocomplétion Docker
  docker-compose             # Autocomplétion Docker Compose
  npm                        # Autocomplétion npm
  pip                        # Autocomplétion pip
  python                     # Aliases python utiles
  command-not-found          # Suggère le paquet apt à installer si commande inconnue
  history                    # Aliases : h (history), hsi (grep dans history)
  colored-man-pages          # Pages man colorées
  extract                    # Commande universelle : extract fichier.tar.gz/zip/rar…
)

source $ZSH/oh-my-zsh.sh

# Zsh-autosuggestions config ───────────────────────────────────────────────
ZSH_AUTOSUGGEST_HIGHLIGHT_STYLE="fg=#888888"   # Couleur de la suggestion
ZSH_AUTOSUGGEST_STRATEGY=(history completion)   # Historique d'abord, puis completions système
bindkey '→' autosuggest-accept                  # Flèche droite pour accepter
bindkey '^ ' autosuggest-accept                 # Ctrl+Espace aussi

# Completions ──────────────────────────────────────────────────────────────
fpath+=${ZSH_CUSTOM:-${ZSH:-~/.oh-my-zsh}/custom}/plugins/zsh-completions/src
autoload -Uz compinit && compinit

# Zoxide (remplace cd intelligemment) ──────────────────────────────────────
eval "$(zoxide init zsh)"
alias cd="z"   # cd pointe maintenant sur zoxide

# Historique boosté ────────────────────────────────────────────────────────
HISTSIZE=50000
SAVEHIST=50000
HISTFILE=~/.zsh_history
setopt HIST_IGNORE_DUPS       # Pas de doublons
setopt HIST_IGNORE_SPACE      # Commandes précédées d'un espace non sauvegardées
setopt SHARE_HISTORY          # Partage l'historique entre les terminaux ouverts

Ensuite applique les changements :

source ~/.zshrc

Résumé des raccourcis clés après installation

Raccourci Action
→ ou Ctrl+Espace Accepte la suggestion de l'historique
Ctrl+R Recherche floue dans tout l'historique (via fzf)
z monprojet Saute dans le dossier monprojet peu importe où tu es
Double Echap Ajoute sudo devant la commande en cours
extract fichier.zip Décompresse n'importe quel format automatiquement
hsi motclé Grep dans l'historique
