Aide-mémoire · Virtualisation

Relier son PC à GNS3

Sur ton poste physique :

Créer une vraie interface TAP isolée

sudo ip tuntap add tap0 mode tap
sudo ip link set tap0 up

Lui attribuer une IP dans ton LAN

sudo ip addr add 192.168.1.50/24 dev tap0

Assure-toi que 192.168.1.50 n’est pas déjà utilisée.

Dans GNS3

Attribuer la carte dans le LAN de GNS3

Créer un device cloud

Clique droit > Configure. Aller à l'onglet TAP interfaces. Ajouter l'interface tap0. Puis valider.

Vérifier en accédant à l'interface web d'un service hébergé

Après un redémarrage 

sudo ip link set tap0 up
sudo ip addr add 192.168.10.50/24 dev tap0
sudo ip route add 192.168.1.0/24 via 192.168.10.254 dev tap0
sudo ip route add 192.168.20.0/24 via 192.168.10.254 dev tap0
sudo ip route add 192.168.30.0/24 via 192.168.10.254 dev tap0

Configurer des route pour l'accès aux autres VLANs depuis notre machine :

sudo ip route add 192.168.1.0/24 via 192.168.10.254 dev tap0
sudo ip route add 192.168.20.0/24 via 192.168.10.254 dev tap0
sudo ip route add 192.168.30.0/24 via 192.168.10.254 dev tap0

Mettre des routes prioritaire :

sudo ip route add default via 192.168.10.254 dev tap0 metric 200

# Avec la virtual IP
sudo ip link set tap0 up
sudo ip addr add 192.168.10.50/24 dev tap0
sudo ip route add 192.168.1.0/24 via 192.168.10.250 dev tap0

sudo ip route add 192.168.30.0/24 via 192.168.10.250 dev tap0
