Tailscale (subnet router)

Installation et configuration de Tailscale

  1. Créez un compte Rendez-vous sur tailscale.com et créez un compte gratuit (Google, Microsoft ou email).

  2. Installez l’application

curl -fsSL https://tailscale.com/install.sh | sh
  1. Connectez-vous
sudo tailscale up

Un lien s’affiche pour autoriser l’appareil dans votre navigateur.

  1. Vérifiez la connexion
tailscale status

Vous devriez voir votre machine avec son IP Tailscale (100.x.x.x).

  1. Répétez sur vos autres appareils

Subnet router - accéder au LAN complet

  1. Activez le routage IP sur la machine qui servira de passerelle (serveur tailscale)
echo 'net.ipv4.ip_forward = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.confecho 'net.ipv6.conf.all.forwarding = 1' | sudo tee -a /etc/sysctl.d/99-tailscale.confsudo sysctl -p /etc/sysctl.d/99-tailscale.conf
  1. Annoncez le sous-réseau
sudo tailscale set --advertise-routes=192.168.212.0/24,192.168.213.0/24
  1. Approuvez la route dans la console Tailscale
  • Allez dans Machines → cliquez sur la machine → Edit route settings
  • Cochez la route annoncée
  1. Sur votre pc pour accéder au route distante
sudo tailscale set --accept-routes
  1. Si vous voulez bloquer l'accès à votre pc 
sudo tailscale set --shields-up
  1. Vérifiez l’accès Depuis un autre appareil Tailscale, pingez une IP du LAN :
ping 192.168.212.254
