Installation de Docker

Ubuntu 24.04Docker Enginedocker compose

Toute la stack (Mailcow, Nextcloud, Collabora) tourne en conteneurs. On installe donc Docker Engine une bonne fois, puis on applique l'étape post-installation pour piloter Docker sans sudo.

Installation de Docker Engine

On suit la procédure officielle pour Ubuntu (dépôt APT officiel plutôt que le paquet de la distribution, pour avoir une version à jour et docker compose intégré) :

docs.docker.com — Install Docker Engine on Ubuntu →

Étape post-installation

Pour exécuter les commandes Docker sans sudo, on ajoute l'utilisateur au groupe docker :

sudo usermod -aG docker $USER

Il faut rouvrir une session pour que l'appartenance au groupe soit prise en compte.

docs.docker.com — Post-installation steps →

SécuritéAppartenir au groupe docker équivaut à un accès root sur la machine (on peut monter n'importe quel volume hôte). On réserve donc ce droit aux seuls comptes d'administration.
